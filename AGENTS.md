# Codex: auditoría y mejora de calidad

Rama de trabajo: `codex/skills-audit-2026-11`.

## Reglas
- No modificar `main`, producción, DNS, Cloudflare, bases de datos ni secretos.
- No desplegar, fusionar pull requests ni ejecutar migraciones remotas.
- Identificar el stack real antes de instalar o ejecutar herramientas.
- Auditar procedencia, licencia, mantenimiento, permisos y scripts de cada skill/plugin/MCP; no ejecutar instaladores remotos sin revisión.
- Revisar UI/UX, responsive, accesibilidad WCAG 2.2 AA, SEO técnico, AEO/GEO, rendimiento y seguridad.
- Mantener marca y funcionalidades. Documentar hallazgos, capturas y resultados de pruebas reales.
- Proponer cambios en PR y esperar aprobación.

El catálogo de 30 herramientas es una lista de candidatas: este archivo no implica su instalación.
